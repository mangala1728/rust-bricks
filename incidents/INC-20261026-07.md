# 缺陷通報：Weibull 可靠度、卡方 CDF、Box-Cox 因 fast_exp_f64 發散而錯誤（CDF 可為負）

## 1. 發現情境與影響
src/spc_msa_advanced.rs:193 fast_exp_f64 為 12 項 Maclaurin、無範圍縮減：exp(-8)=55.6、exp(-10)=925、exp(10)=17435。另 Weibull 在 t=0 時 fast_ln(0)=0 導致 R(0)=e^-1。卡方 CDF 可回傳 -8.0 這種不可能的機率。測試只測 t=η 與 z≈0.15。

## 2. 最小重現代碼（Reproduction Snippet）
```rust
assert_eq!(spc_msa_advanced::spc_weibull_reliability_step(0.0, 100.0, 2.0), Some(1.0)); // 實得 0.3679
let r = spc_msa_advanced::spc_weibull_reliability_step(300.0, 100.0, 2.0).unwrap();
assert!(r < 1e-3, "R = {r}"); // 實得 1.0（應 1.23e-4）
let p = spc_msa_advanced::spc_chi_square_cdf_approx(40.0, 10).unwrap();
assert!((0.0..=1.0).contains(&p), "p = {p}"); // 實得 -8.005
```
（已於 commit 2a66ba7、`--target x86_64-unknown-linux-gnu` 實際執行重現）

## 3. 預期行為 vs 實際行為
- **預期**：R(0)=1；R(300;η=100,β=2)=e^-9≈1.23e-4；χ²CDF(40,10)≈0.99998
- **實際**：0.368 / 1.0 / -8.005

## 4. 排障日誌與修復方案（由工兵填寫）
建議方向：改用 `f64::exp`；t=0 特判回傳 1.0；erf 改用正確近似（A&S 7.1.26 + std exp）。

（排障完成後，填入修復 commit hash 並將 status 改為 RESOLVED）
