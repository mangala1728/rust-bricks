# 缺陷通報：合法 domain 內 dummy_cycles ≥ 9 陣列越界 panic

## 1. 發現情境與影響
src/comm_controller.rs:30-42。@domain 宣告 dummy_cycles [0..16]，但 out_frame 為 [u8; 8]，total_len = 4 + (dummy_cycles+1)/2，dummy_cycles=9 時寫入 out_frame[8] → panic（debug 與 release 皆然）。測試只用 6。

## 2. 最小重現代碼（Reproduction Snippet）
```rust
let mut f = [0u8; 8];
let r = std::panic::catch_unwind(move || comm_controller::qspi_flash_fast_read_cmd(0x123456, 9, &mut f));
assert!(r.is_ok()); // 實際：panic 'index out of bounds: the len is 8 but the index is 8'
```
（已於 commit 2a66ba7、`--target x86_64-unknown-linux-gnu` 實際執行重現）

## 3. 預期行為 vs 實際行為
- **預期**：合法輸入應回傳長度或 0，不得 panic
- **實際**：panic: index out of bounds (src/comm_controller.rs:42)

## 4. 排障日誌與修復方案（由工兵填寫）
建議方向：將緩衝區加大到 [u8; 12]，或把 @domain 與守衛收斂為 dummy_cycles ≤ 8。

（排障完成後，填入修復 commit hash 並將 status 改為 RESOLVED）
