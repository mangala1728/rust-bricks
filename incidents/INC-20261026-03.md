# 缺陷通報：積分圖區域和因 saturating_sub 截斷負中間值而錯誤

## 1. 發現情境與影響
src/vision_feature.rs:146。`br.saturating_sub(bl).saturating_sub(tr).saturating_add(tl)`：br-bl-tr 合法地可為負，被截為 0 後再加 tl 得到錯誤結果。只要框不貼齊左上角就可能出錯。現有測試只測整張圖的框。

## 2. 最小重現代碼（Reproduction Snippet）
```rust
let ii = vision_feature::integral_image_compute(&[255, 0, 0, 0], 2, 2).unwrap();
assert_eq!(vision_feature::integral_box_sum(&ii, 3, 1, 1, 2, 2), 0); // 實得 255
```
（已於 commit 2a66ba7、`--target x86_64-unknown-linux-gnu` 實際執行重現）

## 3. 預期行為 vs 實際行為
- **預期**：2×2 影像 [[255,0],[0,0]] 右下格區域和 = 0
- **實際**：255

## 4. 排障日誌與修復方案（由工兵填寫）
建議方向：改為 `(br.wrapping_add(tl)).wrapping_sub(bl).wrapping_sub(tr)` 或 `(br + tl) - (bl + tr)`（u64）。

**修復**（commit `65fa457`，分支 `worker/review-2026-10-26`）：改用 wrapping 運算 `br - bl - tr + tl`（模 2^32），新增非左上角子框測試。

迴歸測試：`tests/all_bricks.rs`（Red → Green）。
