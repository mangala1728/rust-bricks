# 缺陷通報：SLERP 與軸角轉換因 acos/sin/cos 近似失準，輸出非單位四元數、非正交矩陣

## 1. 發現情境與影響
src/robotics_6dof_slerp.rs 私有 fast_acos_approx / fast_sin_approx / fast_cos_approx：acos(1)=0.404（應 0）、cos(π)=-1.211、sin(π)=-0.075。SLERP 端點不重現且 norm≠1；identity 矩陣轉軸角得 θ=0.404；大角度旋轉矩陣不正交；重力力矩近 ±π 誤差 21%。測試只用 dot=0 或 90°（近似恰好準的點）。

## 2. 最小重現代碼（Reproduction Snippet）
```rust
let s = 0.5f64.sqrt();
let q = robotics_6dof_slerp::robotics_quaternion_slerp_step([1.0, 0.0, 0.0, 0.0], [s, 0.0, 0.0, s], 1.0);
let n = q.iter().map(|x| x * x).sum::<f64>().sqrt();
assert!((n - 1.0).abs() < 1e-6, "norm = {n}"); // 實得 1.0192
assert!((q[0] - s).abs() < 1e-6); // 實得 0.72067
```
（已於 commit 2a66ba7、`--target x86_64-unknown-linux-gnu` 實際執行重現）

## 3. 預期行為 vs 實際行為
- **預期**：t=1 應精確回傳 q2 = [0.7071,0,0,0.7071]，norm = 1
- **實際**：[0.72067,0,0,0.72067]，norm 1.0192

## 4. 排障日誌與修復方案（由工兵填寫）
建議方向：改用 `f64::acos/sin/cos`。
