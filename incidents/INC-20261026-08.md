# 缺陷通報：PM2.5 AQI 最高段斷點合併錯誤（且為 2024 前舊表）

## 1. 發現情境與影響
src/env_sensor.rs:51。把 EPA 的 250.5–350.4→301–400 與 350.5–500.4→401–500 合併為單一 250.5–500.4→301–500。另：EPA 自 2024-05 起已改新表（0–9.0→0–50 等），濃度也未先截斷到 0.1。

## 2. 最小重現代碼（Reproduction Snippet）
```rust
assert_eq!(env_sensor::aqi_pm25_us_standard(350.4), 400); // 實得 381
```
（已於 commit 2a66ba7、`--target x86_64-unknown-linux-gnu` 實際執行重現）

## 3. 預期行為 vs 實際行為
- **預期**：350.4 µg/m³ → AQI 400（EPA 舊表亦同）
- **實際**：381

## 4. 排障日誌與修復方案（由工兵填寫）
建議方向：拆分最後兩段斷點；並決定採 2024 新表或於文件註明舊表。

**修復**（commit `b8de1b9`，分支 `worker/review-2026-10-26`）：最高段拆為 250.5–350.4→301–400 與 350.5–500.4→401–500，並先截斷至 0.1 µg/m³；文件註明使用 2024-05 修訂前之舊表（是否改採新表待維護者決定）。
