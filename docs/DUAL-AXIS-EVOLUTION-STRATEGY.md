# 雙軸演化大局思維：廣度泛化與深度泛化戰略（Dual-Axis Evolution Strategy）

> **「廣度泛化開疆闢土，建立跨領域微積木橋頭堡；深度泛化深耕細作，打穿工業級與晶片級技術護城河。」**  
> 本指南規範 `rust-bricks` 核心團隊（指揮官＋工兵＋審查員＋品質總監）在大局思維下的雙軸持續推進戰略。

---

## 一、雙軸演化的核心哲學（The Dual-Axis Dilemma & Synthesis）

在軟體工程與高安全積木庫開發中，常見兩種極端失敗模式：
1. ❌ **盲目廣度（The Shallow Toy Trap）**：到處開新專案、每種主題只做個 `hello_world`，看似什麼都有，實則在真實工業場景一戳就破，毫無實用價值。
2. ❌ **過早沉溺深度（The Ivory Tower Trap）**：在單一冷門數學領域耗費數月優化到極致，但外界毫無調用場景，錯失邊緣裝置跨領域高頻爆發的市場先機。

**指揮官的大局思維（Commander's Strategic Orchestration）**：
- **動態平衡節奏**：以「**攻下一個新領域橋頭堡（廣度探索）＋ 縱向深化一個既有領域（深度護城河）**」交替自驅推進。
- **由許願池驅動深度**：外部專案 AI 代理在實際接入時提出的 WISH，往往精準指出當前領域最迫切的「深度痛點」，是指揮官排定深度任務的黃金指針。

```text
       ▲ 縱向：深度泛化 (Vertical Depth)
       │  • 打穿行業壁壘、通訊協議位元級解析
       │  • 工業量產級極限效能、零拷貝、防溢出
       │  • 例：CAN DBC 信號跨字節解包、ISO 8583 報文點陣圖
       │
       │       ★ 黃金演化路徑 (The Gold Path)
       │         交替自驅：橫向拓荒 ➔ 縱向固壘
       │
       └────────────────────────────────────────► 橫向：廣度泛化 (Horizontal Breadth)
          • 跨足新垂直領域與產業橋頭堡
          • 解決零依賴微積木真空
          • 例：手機觸控、音訊DSP、車載CAN、金融卡、3D VR物理、溫控PID、Agent Harness
```

---

## 二、維度一：跨領域的「廣度泛化」（Horizontal Frontier）

### 1. 核心任務
探索陌生技術領域，以最小有界代碼提煉該領域觸發最頻繁、最耗電、最容易產生 GC 停頓的純演算法核心，重現為 Rust 零依賴微積木。

### 2. 已建立的八大廣度橋頭堡
1. **手機微交互與觸控**：`touch_control`（消抖、EMA 速度追蹤、三階遲滯）。
2. **音訊與語音 DSP**：`audio_dsp`, `audio_vad`, `audio_wav`, `ring_buffer`。
3. **邊緣影像特徵萃取**：`vision_feature`, `vision_yuv`（NV21 抽取、Otsu 二值化、Sobel）。
4. **車載總線與 MCU 韌體**：`can_bus_frame`（11/29-bit CAN ID 拆解、CAN FD DLC 映射、Modbus RTU）。
5. **金融終端與智慧卡安全**：`iso7816_smartcard`（Luhn 校驗、Format 0 PIN Block、EMV BER-TLV）。
6. **3D 虛擬實境與遊戲物理**：`spatial_physics`（四元數旋轉、射線-球體碰撞、彈簧阻尼系統）。
7. **工業閉環溫控與電氣採樣**：`thermal_pid`（抗積分飽和 PID、10k NTC 測溫、人眼知覺 LED 映射）。
8. **AI 代理馬具與 PTY 路由**：`agent_terminal`（ANSI 脫色、非遞迴 Glob 匹配、PTY 退格編輯）。

## 三、維度二：已有主題的「深度泛化」（Vertical Frontier）

### 1. 核心任務
將既有模組從「單純能用」深耕至「工業量產級、晶片標準級、物理極限級」，消滅底層 C/C++ 庫常有的緩衝區溢出與未定義行為。

### 2. 深度泛化的三大範例落地
- **車載總線縱向深化**：
  - *廣度基礎*：單純判定 11-bit / 29-bit CAN ID。
  - *深度打穿*：實作 **`can_signal_unpack_u32`**——支援車載 DBC (CAN Database) 跨位元組（跨 byte 1 與 byte 2）任意起始位元與長度（1..32 位元）的小端無號整數快速解碼，一行位元遮罩消滅 C 語言手寫溢出風險。
- **金融智慧卡縱向深化**：
  - *廣度基礎*：單純校驗卡號與 PIN Block。
  - *深度打穿*：實作 **`iso8583_bitmap_is_present`**——銀行跨行清算與 ATM/POS 核心的 ISO 8583 報文 64 位點陣圖判定，常數時間 $O(1)$ 判定交易資料欄位是否存在，杜絕記憶體越界。
- **音訊 DSP 縱向深化（未來規劃）**：
  - *廣度基礎*：單純 RMS 能量與靜音幀判定。
  - *深度打穿*：定點數 Q15 FFT（快速傅立葉變換）、Hanning 窗函式、自適應迴音消除（AEC）。

## 四、指揮官在大局中的調度原則（Commander's Operating Principles）

1. **70/30 動態權衡**：
   - 新領域開闢期：70% 廣度覆蓋（搶佔生態位）＋ 30% 深度加固。
   - 專案量產期：70% 深度深耕（打穿技術瓶頸）＋ 30% 廣度探索。
2. **許願池與 Defect Gate 雙軌輸入**：
   - 當 `wishes/` 累積同領域多個需求時，自動觸發該領域的「深度泛化專題」。
   - 當 `incidents/` 爆出邊界問題時，觸發品質總監的「逆向混沌再抽檢」。
3. **零妥協品質底線**：
   - 無論廣度擴張或深度深耕，一律嚴格遵守 NASA JPL 60 行原則、06/09 號合約守衛、零外部依賴與品質總監黑箱 0 崩潰保證！
