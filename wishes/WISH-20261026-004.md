## 1. 需求背景與場景（Context）
- 使用專案：雙向即時語音口譯 Android App（ai-interpreter）。
- 遇到瓶頸：Android 裝置麥克風原生硬體採集頻率多為 48,000 Hz，而 Gemini 與本機端 LiteRT 語音特徵提取器要求 16,000 Hz。目前在 Kotlin 中使用三倍降採樣加內插，計算效率低且動態範圍不足，遠距離說話聲音偏小。

## 2. 原語言代碼或演算法本質（Source Algorithm）
- 原語言：Kotlin (`com.example.aiinterpreter.core.audio.Resampler`)
- 演算法本質：
  1. 3:1 降取樣帶通濾波（Polyphase Decimation 48kHz -> 16kHz），抑制高頻混疊（Anti-aliasing）。
  2. 自動增益控制（Automatic Gain Control, AGC）：追蹤 RMS 能量包絡線，動態調節線性縮放因數，將低聲講話（<-28 dBFS）拉抬至標準電平（-18 dBFS），並搭配雙曲正切或軟削峰防爆音。

## 3. 期望的 Rust 微積木簽章（Target Signature）
```rust
/// @outputs: 1
pub fn downsample_3to1_pcm16(input_48k: &[i16], output_16k: &mut [i16]) -> usize;

/// @domain: max_gain [1.0..10.0]
pub fn agc_apply_gain_pcm16(samples: &mut [i16], target_dbfs: f32, max_gain: f32);
```

## 4. 效益與指標（ROI）
- 記憶體優化：原地（In-place）或重用緩衝區處理，零短生命週期物件分配。
- 速度提升：由 Kotlin 的 ~2.1ms/幀 縮短至純 Rust 的 < 0.08ms/幀。
