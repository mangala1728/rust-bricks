## 1. 需求背景與場景（Context）
- 使用專案：雙向即時語音口譯 Android App（ai-interpreter 常用金句庫 Phrasebook）。
- 遇到瓶頸：使用者搜尋 300+ 常用金句（中英印多語）時，若輸入有打字輕微錯誤或語音辨識同音字差一兩字，現有 Kotlin 遍歷 Levenshtein 演算法速度偏慢，且在高頻即時搜尋（用戶每按一個按鍵或說一個詞即重新搜尋）時造成 UI 掉幀。

## 2. 原語言代碼或演算法本質（Source Algorithm）
- 原語言：Kotlin (`com.example.aiinterpreter.core.phrase.PhraseSearch`)
- 演算法本質：
  1. 雙列滾動緩衝區（Two-row rolling array）動態規劃 Levenshtein Distance 計算。
  2. 前綴加權相似度（Jaro-Winkler 啟發式前綴強化）。
  3. 支援 Unicode Scalar / CJK 字元與 Devanagari 組合字元安全比對。

## 3. 期望的 Rust 微積木簽章（Target Signature）
```rust
/// @outputs: 1
/// @domain: max_dist [0..50]
pub fn levenshtein_distance_bounded(s1: &str, s2: &str, max_dist: usize) -> usize;

/// @outputs: 1
pub fn fuzzy_prefix_match(query: &str, target: &str) -> bool;
```

## 4. 效益與指標（ROI）
- 記憶體優化：零 Heap Allocation，在 Stack 上使用滾動 `[usize; 64]` 陣列。
- 速度提升：搜尋 500 筆常用金句延遲由 Kotlin 的 14ms 降至純 Rust 的 < 0.2ms，確保鍵盤輸入與語音聯想 60fps 絲滑無感。
