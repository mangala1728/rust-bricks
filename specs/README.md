# 規格書目錄與工程邊界撰寫指南 (Specifications & Sub-function Contracts)

```text
## Map
┌──────────────────────────────────────────────────────────────────────────────┐
│                    定義者 (Architect) 撰寫 specs/*.md                        │
│   • 依循 template.md、指定下水道單位刻度、提供機器可驗證黃金向量 (```golden)   │
└──────────────────────────────────────▲───────────────────────────────────────┘
                                       │
┌──────────────────────────────────────┴───────────────────────────────────────┐
│                    雲端農夫 (Cloud Farmer) / 寫碼工兵                        │
│   • 自動讀取 specs/*.md、實作 09 號合約微積木、第一行邊界守衛、NASA JPL <= 60 行 │
└──────────────────────────────────────▲───────────────────────────────────────┘
                                       │
┌──────────────────────────────────────┴───────────────────────────────────────┐
│                    用戶 / 上游 AI 代理 (Consumer Agent)                      │
│   • 依據度量衡刻度進行尺度縮放 (Scale-Up)、安全呼叫、零拷貝 32B 匯流排對接    │
└──────────────────────────────────────────────────────────────────────────────┘
```

本目錄包含 `rust-bricks` 庫所有功能模組的規格書（Specifications）。  
為了讓**定義者（Architect）、碼工（Coder / Cloud Farmer）、用戶（AI 代理 / 上游系統）**三方在同一把尺、相同的刻度上協同工作，所有規格書與實作必須嚴格遵守以下準則：

- **通用度量衡與下水道刻度總綱**：詳見 [`docs/SUBFUNCTION-BOUNDARY-AND-PIPE-STANDARDS.md`](../docs/SUBFUNCTION-BOUNDARY-AND-PIPE-STANDARDS.md)。
- **規格書公版模板**：詳見 [`specs/template.md`](template.md)。

## 一、通用精度與單位對照速查表（The Universal Scale）

| 領域 | 規格標度 | 單位與因子 | 範圍 (Domain) | 說明 |
|---|---|---|---|---|
| **時間 (Bus 1)** | `ts_us: u64` | 微秒 (1 us) | `0..1.84e19` | 高速事件二進位磁軌 |
| **時間 (Bus 2)** | `ts_sec: u64` | 秒 (1 s) | `0..4.10e9` | 歷史雙時態地層庫 |
| **角度 (黃道/經緯)** | `milli_deg: u32/i32` | 毫度 ($10^{-3}$ deg) | `0..360000` | 經度/黃經毫度定點數 |
| **角度 (角分)** | `arcmin: u32` | 角分 ($1/60$ deg) | `0..21600` | 毫度轉角分：$(\text{milli}\times 3)/50$ |

## 二、三方協同守則摘要

1. **定義者（Architect）**：
   - 撰寫新規格請拷貝 `specs/template.md`。
   - 必須提供不可篡改之確定性黃金向量區塊（` ```golden `）。
   - 數值參數必須宣告 `@domain` 與輸出基數 `@outputs`。
2. **碼工／雲端農夫（Coder）**：
   - 檔案開頭必附 `## Map`。
   - 函式第一行剛性實作邊界檢核：`if param < min || param > max { return None; }`。
   - NASA JPL $\le 60$ 行，巢狀深度 $\le 2$，零 `static mut`，零遞迴。
   - 嚴格遵守 14 大工程鐵律（標準庫數學優先、拒絕弱斷言、全鏈條防溢位）。
3. **用戶／AI 代理（Consumer）**：
   - 呼叫子函數前，先於 [`CATALOG.yaml`](../CATALOG.yaml) 檢索參數定義域。
   - 傳入參數必須前置尺度縮放（例如度數乘以 1000 轉毫度）。
   - 所有回傳 `Option` 或 `Result` 必須安全解包，妥善處理邊界收斂。
